# 开个青楼 · 听雨楼经营记

一款手机与桌面浏览器均可游玩的古代艺馆经营模拟游戏。

从临河旧楼起步，招揽琴师、舞师与清客，安排节目、处理楼中风波、经营四方宾客关系，最终把听雨楼建成天下名楼。

## 游戏特色

- 排节目、选阵容、按旬推进并处理随机事件
- 琴艺、舞艺、辞令、待客四维养成
- 文士、商贾、游侠、权贵四类宾客关系
- 招募、研习、设施置办与楼业扩张
- 本地自动存档与八年名楼评定
- 适配手机窄屏，无需安装即可游玩

> 本作为非露骨经营游戏，重点是才艺培养、席面调度、口碑与人情网络。
